# Football Scouting Reports

A player scouting report project built using **Python, FotMob API, and Tableau**.

The Python pipeline collects player performance data across seasons and competitions, transforms the data into a structured scouting dataset, and prepares it for analysis in Tableau.

The final Tableau report combines player profile information, performance trends, per-90 metrics, and scouting observations into an interactive player report.

We used Troy Parrott as our main example for the final dashboard.

## Tools

* Python
* FotMob API
* Pandas
* Tableau
* GitHub

## Project Workflow

**FotMob API → Python → CSV → Tableau → Scouting Report**
